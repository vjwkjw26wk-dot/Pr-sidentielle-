# Contenu domestique d'un euro de consommation par quintile de niveau de vie (version 0.6)

Analyse entrées-sorties statique, tableau 2022 ; passerelle fonctions → produits avec marges et impôts (hypothèse) ; structures de consommation par quintile de l'Insee (2022). Les marges de commerce et de transport sont de la valeur ajoutée nationale même quand le produit est importé.

| Q3 | 14.3 % | 28.1 % | 56.1 % | 10.2 % | 6.0 % | 7.2 k |
| Q4 | 14.2 % | 28.1 % | 56.2 % | 10.3 % | 5.8 % | 7.3 k |
| Q5 | 14.5 % | 28.1 % | 55.8 % | 10.5 % | 5.7 % | 7.4 k |

Somme impôts + importations + VA ≈ 100 % (écart : arrondis et produits hors passerelle).

Lecture : l'écart de contenu importé entre quintiles reste faible ; les différences portent davantage sur la composition sectorielle (logement et énergie chez les modestes, services marchands chez les aisés) et sur le contenu en emplois par euro (plus élevé dans les services de proximité, plus faible dans le logement, très capitalistique).
