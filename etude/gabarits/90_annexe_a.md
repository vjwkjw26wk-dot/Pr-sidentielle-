# Registre des paramètres, valeurs, unités et sources {#sec:annexe-a}

Statuts : [D] donnée ou règle publiée ; [E] estimé par le projet ; [C] calibré (littérature ou cible) ; [H] hypothèse ;
[X] exploratoire ; confiance A à D (registre de la version 0.8). Les coefficients des équations à correction d'erreur
(consommation, investissement, commerce, emploi, salaires, prix) sont donnés au chapitre \ref{sec:equations} ; les
effets fixes de branche et les constantes de calage sont dans le code (`src/m7_equations.py`, cache des
environnements).
